**一句话结论**：**第三方中文镜像** —— 读英文文档卡住时对照用，但**关键 API 以英文原版为准**。

## 镜像站的使用规则

这类材料的价值与风险都很明确：

| | 说明 |
|---|---|
| **价值** | 术语与表述的中文化，降低初次阅读门槛 |
| **风险** | **版本可能落后于官方**，关键 API 可能已经变了 |

**所以有一条硬规则：涉及 API 名称、参数、行为的，以英文原版为准。** 中文镜像用来理解**概念**，不用来确认**接口**。

## 为什么这条规则重要

本站第 14 章复核时踩过一个具体的例子：**MCP 的 URL 里带着版本日期，而内容已经是一次破坏性修订。**

那次是「同一个站点更新了内容」，而镜像站的风险是「**另一个站点没有跟上**」—— 表现相同（你对不上接口），原因不同。

**两种情况的判据都一样：看版本与日期，不看页面是否可达。** 这也是本站 `verifiedAt` 字段存在的理由。
