摘要：
语言模型（LMs）展现出显著的能力，能够仅凭少量示例或文本指令解决新任务，尤其是在规模化时。但矛盾的是，它们在基础功能上却表现不佳，例如算术或事实查找，而这些方面更简单、更小的模型反而更擅长。在本文中，我们表明，LMs 可以通过简单的 API 教会自己使用外部工具，从而实现两全其美。我们介绍了 Toolformer，这是一个经过训练的模型，用于决定调用哪些 API、何时调用它们、传递什么参数，以及如何最好地将结果纳入未来的 token 预测。这是以自监督方式完成的，每个 API 只需要少量演示。我们纳入了一系列工具，包括计算器、Q\&A 系统、两个不同的搜索引擎、翻译系统和日历。Toolformer 在各种下游任务上实现了显著 improved 的 zero-shot 性能，通常可与大得多的模型竞争，同时不牺牲其核心语言建模能力。
