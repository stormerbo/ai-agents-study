Dify 是一个开源的 LLM 应用开发平台。其直观的界面融合了 AI workflow、RAG pipeline、agent 能力、模型管理、可观测性特性（包括 [Opik](https://www.comet.com/docs/opik/integrations/dify)、[Langfuse](https://docs.langfuse.com) 和 [Arize Phoenix](https://docs.arize.com/phoenix)）等，让你能够快速从原型走向生产。以下是核心特性列表：

## 快速开始

> 在安装 Dify 之前，请确保你的机器满足以下最低系统要求：
>
> - CPU >= 2 核
> - RAM >= 4 GiB

<br/>

启动 Dify 服务器最简单的方式是通过 [Docker Compose](docker/docker-compose.yaml)。在使用以下命令运行 Dify 之前，请确保你的机器上已安装 [Docker](https://docs.docker.com/get-docker/) 以及 Docker Compose v2.24.0 或更高版本：

```bash
cd dify
cd docker
cp .env.example .env
docker compose up -d
```

运行后，你可以在浏览器中通过 [http://localhost/install](http://localhost/install) 访问 Dify dashboard，并开始初始化流程。

### 寻求帮助

如果你在搭建 Dify 时遇到问题，请参阅我们的 [FAQ](https://docs.dify.ai/getting-started/install-self-hosted/faqs)。如果仍有疑问，请联系[社区和我们](#community--contact)。

> 如果你想为 Dify 做贡献或进行额外的开发，请参阅我们的[从源代码部署指南](https://docs.dify.ai/getting-started/install-self-hosted/local-source-code)

## 关键特性

**1. Workflow**：
在可视化画布上构建和测试强大的 AI workflow，充分利用以下所有特性以及更多能力。

**2. 全面的模型支持**：
与来自数十个 inference provider 和自托管解决方案的数百个专有/开源 LLM 无缝集成，覆盖 GPT、Mistral、Llama3 以及任何 OpenAI API 兼容的模型。支持的模型 provider 完整列表见[此处](https://docs.dify.ai/getting-started/readme/model-providers)。

![providers-v5](https://github.com/langgenius/dify/assets/13230914/5a17bdbe-097a-4100-8363-40255b70f6e3)

**3. Prompt IDE**：
直观的界面，用于编写 prompt、比较模型表现，以及为基于聊天的应用添加 text-to-speech 等额外功能。

**4. RAG Pipeline**：
全面的 RAG 能力，涵盖从文档摄取到检索的各个环节，开箱即用支持从 PDF、PPT 及其他常见文档格式中提取文本。

**5. Agent**：拥有自己沙箱的自主 agent：它们运行命令、安装软件并处理文件，以完成开放式任务。描述你想要的 agent，它便会自行构建。赋予它技能，连接来自 [Dify Marketplace](https://marketplace.dify.ai/?category=tool)、MCP server 或你自己的 API 的工具，然后让它作为聊天应用或任意 workflow 中的一个步骤投入工作。

**6. LLMOps**：
随时间监控和分析应用日志与性能。你可以基于生产数据和标注持续改进 prompt、dataset 和模型。

**7. Backend-as-a-Service**：
Dify 的所有产品都配有相应的 API，因此你可以毫不费力地将 Dify 集成到你自己的业务逻辑中。

## 使用 Dify

- **Cloud <br/>**
  我们托管了 [Dify Cloud](https://cloud.dify.ai)，因此你无需管理服务器即可试用 Dify。当前套餐和使用额度见[定价页面](https://dify.ai/pricing)。如果你遇到问题，请[联系我们的 Cloud 支持团队](mailto:cloud@dify.ai?subject=%5BGitHub%5DDify%20Cloud%20Support)。

- **自托管 Dify Community Edition<br/>**
  参照这份[入门指南](#quick-start)，快速在你的环境中运行 Dify。
  请参阅我们的[文档](https://docs.dify.ai)以获取更多参考和更深入的说明。

- **[Dify Enterprise](https://dify.ai/dify-enterprise)<br/>**
  对于需要自托管、SSO、RBAC 安全性和企业支持 SLA 的组织，请填写[此表单](https://share-na2.hsforms.com/14-09ff5HS92Sh4m3f4yrcw40s9fk)以与解决方案代表沟通。<br/>
