**一句话结论**：少见的**多语言并列**文档（Python / TypeScript / Go / Java / Kotlin）—— 对有多种后端语言背景的人是加分项。

## 为什么多语言并列有价值

本站的目标读者是有 Java / Python / Go 背景的后端工程师（`AGENTS.md` §1）。**多数 agent 框架只提供 Python 与 TypeScript 两种实现** —— 而这一份给了五种。

这意味着你可以**在熟悉的语言里读框架的抽象**，而不是先跨语言再理解概念。

**第二个好处是对照**：同一套概念在五种语言里的表达方式不同，**看它们怎么各自表达「工具」「状态」「转移」**，反而更容易看清哪些是本质、哪些是语言习惯。

## 另外两个小优点

- **提供 `llms.txt`** —— 供编码工具读取的结构化索引（MCP 文档也这么做，这是 2026 年逐渐成型的做法）
- **已迁到独立域名** `adk.dev` —— 本站首轮核实时抓到了这次迁移（原链接指向 Google 域名）
