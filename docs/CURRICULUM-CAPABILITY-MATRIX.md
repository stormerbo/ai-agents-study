## 级别如何解释

- **0 缺失**：找不到明确教学目标。
- **1 能解释**：能说明概念、边界和失败形态。
- **2 受限练习**：能在给定输入、依赖和约束下实现，并按判据检查结果。
- **3 项目集成**：能把能力集成到阶段作品，处理负向路径并交付可复查证据。

这些级别是待评估的学习结果定义，不是当前学习者成绩。课程、实验或项目代码存在不等于达到等级。毕业判定要有具体学习者产物、按 rubric 评分的记录、相关 gate 证据和 reviewer；涉及安全、权限、副作用、恢复的 hard gate 不得用平均分抵消。Stage 5 的官方 holdout 与独立交接必须由外部受信角色执行，仓库内 fixture 和文档检查不能替代。

## 维护规则

课程 ID、lab ID、project ID 和 rubric ID 改动时必须同步本表。新增能力必须同时写出教学入口、练习、可观察判据和证据状态；若任一处为空，标为“教学缺口”或“评估缺口”，不得写成已覆盖。审计状态见[逐节审计台账](CURRICULUM-REVIEW-TRACKER.md)；课程事实准确性状态见[准确性审计报告](CURRICULUM-ACCURACY-AUDIT-2026-10-20.md)。
